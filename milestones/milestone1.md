## Reflection

### 1. What went well during this unit?

Defining the core concept and technical scope for SupplyAgent went seamlessly. Setting up the multi-tenant isolation model, Agent-to-Agent (A2A) negotiation workflow, automated Purchase Order (PO) creation, and relational database requirements in PostgreSQL allowed us to build a comprehensive set of user stories and a well-structured README.

### 2. What were some challenges your group faced in this unit?

The primary challenge was balancing the rich feature set—combining enterprise multi-tenant isolation, automated event triggers for PO generation, and complex relational PostgreSQL schemas with WEB103 frontend requirements like React Router dynamic navigation and modal overlays. Standardizing user roles and breaking down technical requirements into clear user stories helped resolve this complexity.

### 3. What additional support will you need in upcoming units as you continue to work on your final project?

In upcoming units, additional guidance on optimizing PostgreSQL multi-tenant queries, handling complex async state management in React, and setting up automated Playwright e2e test suites for modal overlays and workflow triggers will be beneficial.
